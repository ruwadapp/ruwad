# تشغيل بوابات المعاهد — دليل سريع

## إطلاق بوابة جديدة (٥ دقائق)
1. لوحة super admin ← **البوابات** ← **بوابة جديدة**.
2. اختر المعهد، اكتب subdomain (أحرف إنجليزية صغيرة/أرقام/شرطات)، الاسم المعروض، رابط الشعار، والألوان الثلاثة — راقب **المعاينة الحية**.
3. حدّد تاريخ انتهاء الاشتراك ← **إنشاء البوابة**.
4. افتح `https://{subdomain}.ruwaad.app` — تعمل فوراً بشهادة SSL (بفضل wildcard `*.ruwaad.app`).

## ربط دومين خاص (ترقية مدفوعة)
1. المعهد يشتري دومينه (~10–15$ سنوياً على حسابه).
2. من بطاقة البوابة ← **إدارة** ← لوحة «الدومين الخاص» ← أدخل الدومين ← **ربط**.
3. أرسل للمعهد سجلّي DNS الظاهرين (A: `76.76.21.21` و CNAME: `cname.vercel-dns.com`) — موجودان أيضاً في شاشة «بوابتي» عنده.
4. بعد إضافتهما عند مسجّل النطاق: زر **تحقق** حتى يتحول لـ«نشط ✓» (دقائق–ساعات حسب انتشار DNS). SSL تلقائي.

## التحصيل والإيقاف
- زر **الإيقاف** ⏸ على البطاقة يعرض «البوابة غير نشطة» على دومين المعهد خلال ≤ دقيقة (عمر كاش الحافة).
- تجاوز **تاريخ الانتهاء** يوقفها تلقائياً بنفس الطريقة؛ التجديد = تحديث التاريخ وإعادة التفعيل.

## ما يحدث تلقائياً
- طالب يسجّل من البوابة ← حساب مركزي + وسم `signup_portal_id` + عضوية معتمدة في المعهد (انضمام ذاتي) — عدّاد «تسجيل عبرها» على البطاقة.
- شهادات طلاب الكورسات المشاركة مع معهدٍ له بوابة نشطة تتلون بهويته.
- مضيف مجهول ← تحويل للمنصة الأم؛ مسارات المصادقة على دومين البوابة تُحوَّل موسومة.

## حدود الإصدار الحالي (بالتصميم)
- تجربة الطالب **بعد الدخول** على المنصة الأم؛ التجربة الكاملة الملوّنة على دومين البوابة ترقية لاحقة (القرار موثق في الخطة).
- المعهد يرى بوابته للقراءة فقط («بوابتي») — كل تعديل عبر إدارة المنصة.

## قبل أول عميل مدفوع
